F1 Aerodynamics Project

External aerodynamics analysis focused on flow structures, pressure distribution, and design comparison.

Project Overview

This project explores the aerodynamic behavior of a Formula 1–style vehicle using steady-state CFD simulations. The focus is on understanding flow separation, wake structures, and pressure distribution around key components.

Simulation Setup

  • Solver: OpenFOAM / ANSYS Fluent
  • Flow regime: Incompressible, steady
  • Turbulence model: k-ω SST
  • Post-processing: Python & ParaView

Key Results

The results highlight the impact of geometry changes on wake size and pressure recovery. Regions of high pressure gradient correlate with increased drag contribution.
