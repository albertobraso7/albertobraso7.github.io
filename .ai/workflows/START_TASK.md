# Start or Resume a Task

1. Read [CURRENT](../tasks/CURRENT.md). Resume valid unfinished work; inspect
   status before deciding whether a new request replaces an objective.
2. Verify the portfolio root, branch/HEAD, working-tree changes, staged diff and
   relevant untracked files. Preserve prior edits; do not assume a clean checkout.
3. Read [PROJECT](../PROJECT.md), [DECISIONS](../DECISIONS.md) and
   [WORKFLOW](../WORKFLOW.md) as relevant. For content, start from
   [SOURCES](../SOURCES.md) and [INVENTORY](../PROJECT_INVENTORY.md).
4. Check freshness of the portfolio and each source whose content will be used,
   following WORKFLOW's fetch/classification procedure. Record dated SHAs and
   failures. If local is behind, inspect the verified remote before implementation;
   do not integrate or discard work automatically.
5. Confirm scope from the user's instructions. Only the portfolio is normally
   writable. Ask only for a required unresolved decision/authorization, while
   continuing independent authorized work. Do not reopen already settled choices.
6. Set CURRENT to `IN_PROGRESS`, name the agent, state a concrete objective and
   checkable acceptance criteria, record pre-existing work and choose targeted checks.
7. Read the smallest sufficient source: portfolio case, README, supporting docs,
   then raw evidence only if needed. Implement in coherent steps and update
   shared memory after material progress. No redesign unless requested.
