# Finish a Task

1. Check each acceptance criterion against files and verification evidence.
   Resolve task-caused failures; leave unrelated existing work intact.
2. Run the smallest appropriate checks in [PROJECT](../PROJECT.md): document
   structure/links for memory changes; browser/asset checks for site changes;
   applicable established tests/build if later added. Include untracked files.
3. Inspect final status and relevant diffs. Confirm no source worktree, unrelated
   file or prior staging was changed. Do not commit or push without an explicit request.
4. Consolidate durable knowledge, source freshness/provenance and decisions in
   the proper shared files. Remove obsolete statements, not valid prior work.
5. Set [CURRENT](../tasks/CURRENT.md) to `COMPLETE` only when this objective is
   fulfilled. Retain all headings; record verification outcomes, limitations,
   files modified and handoff notes. A later synchronization/publication task
   can remain recommended without making completed bootstrap work unfinished.
6. Report outcome, repository status when relevant, important problems and next
   action. Distinguish source availability and current-task completion from
   readiness to build or publish. Never claim unrun validation passed.
